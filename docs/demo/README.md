## Pre-demo checklist

1. API + UI running; FOBO seeded with skill MDs.  
2. Closed window with known traffic (or demo/fixture data).  
3. One completed run with skill gaps + Decide cards if possible.  
4. Hard-refresh UI (full-width + skill side-by-side).  
5. Tabs ready: Setup → Running → Results → Decide → Usage / History.
