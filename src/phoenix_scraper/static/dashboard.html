Validation — are the answers any good?

Every span is judged by deterministic code checks (Phoenix annotator_kind=CODE) covering the answer side (empty, refusal, truncation, repetition, malformed JSON, off-topic, ungrounded figures) and the prompt side (injection, PII, vague asks). Human thumbs-up/down and LLM-judge evals pulled from Phoenix appear here too. Fail rate is failed checks over the checks that applied.
